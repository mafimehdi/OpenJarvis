### مورد ۸ 🔴 — تأخیر ورود («دیر معامله می‌شود»)

**بگردید دنبال:** منطق سیگنالی که در بستن کندل اجرا می‌شود.

هر ۹ سفارش شما در ثانیه ۰ یا ۱ بعد از مرز کندل M15 وارد شده‌اند

```mql4

{
   // سیگنال از کندل بسته‌شده خوانده می‌شود

   OrderSend(Symbol(), OP_BUY, lots, Ask, ...);
```

**دو راه اصلاح:**

**الف) ورود با سفارش معلق** (تأخیر را حذف می‌کند):
```mql4
// سطح سیگنال را از پیش ثبت کن، نه قیمت لحظه‌ای
```

## گام ۳ — بک‌تست را درست بگیرید

نتیجه «عالی» فعلی بی‌اعتبار است، چون:

| | بک‌تست شما | لایو |
|---|---|---|
| اسپرد | ثابت و کوچک | ۳۵ پوینت (تا ۱۶۰) |
| حد ضرر vs اسپرد | بزرگ‌تر | **کوچک‌تر** ❌ |
| مدل OnTick | فقط ابتدای کندل | هر تیک |

در Strategy Tester:
- **Model:** `Every tick` (نه `Open prices only`)
- **Spread:** `Current` یا عدد واقعی Alpari برای XAUUSD
- **Symbol:** همان نماد بروکر واقعی

با مدل `Open prices only`، `OnTick()` فقط یک‌بار در ابتدای هر کندل صدا زده
می‌شود و پر شدن روی `open` همان کندل مدل می‌شود — پس هم تأخیر و هم اسپرد
**نامرئی** می‌شوند. این دقیقاً همان چیزی است که تفاوت را ساخته.

# عیب‌یابی خطاهای کامپایل

## ❌ `event handling function not found  —  <file>.mq4  1  1`

**معنا:** فایل `.mq4` شما هیچ تابع رویدادی ندارد. کامپایلر MQL4 برای یک
اکسپرت **حداقل `OnTick()` را الزامی می‌داند.**

**علت رایج:** محتوای `GF63_Fixes.mqh` در یک فایل `.mq4` گذاشته شده و روی
همان Compile زده شده است. `GF63_Fixes.mqh` یک فایل **include** است —
به‌تنهایی اکسپرت نیست و کامپایل نمی‌شود.

```
❌ اشتباه:  GF63_Fixes.mqh را در MQL4/Experts/ بگذارید و Compile بزنید
✅ درست:   GF63_Fixes.mqh را در MQL4/Include/ بگذارید
```

فایل include باید **داخل** یک اکسپرت موجود `#include` شود:

```mql4
// در فایل اکسپرت GoldFusion (که از قبل OnTick دارد):
#property strict
#include <GF63_Fixes.mqh>

int OnInit()  { GF_SelfTest(); return(INIT_SUCCEEDED); }
void OnTick() { /* کد اصلی اکسپرت شما */ }
```

### اگر می‌خواهید ماژول را جدا تست کنید

فایل **`GF63_Test.mq4`** را در `MQL4/Experts/` بگذارید. این یک اکسپرت کامل

## ❌ خطاهای رایج دیگر

| خطا | علت | راه‌حل |
|---|---|---|
| `'GF_XXX' - function not defined` | فایل include پیدا نشد | `GF63_Fixes.mqh` را در `MQL4/Include/` بگذارید |
| `'GF_XXX' - function is not defined` | ماژول قبل از استفاده include نشده | `#include <GF63_Fixes.mqh>` را **بالای** فایل و بعد از `#property strict` بگذارید |
| `unbalanced parentheses` | نسخه ناقص کپی شده | فایل را کامل و دست‌نخورده کپی کنید |
| `'OnInit' - function already defined` | اکسپرت شما از قبل `OnInit` دارد | `GF_SelfTest();` را **داخل** `OnInit` موجود اضافه کنید، نه یک `OnInit` جدید |
| `'ATR_SL_Floor' - variable already defined` | نام متغیر عمومی شما با ماژول یکی است | نام متغیر خودتان را عوض کنید — همه توابع ماژول با `GF_` شروع می‌شوند |
| `'PrintFormat' - function not found` | بیلد قدیمی MQL4 | MetaEditor را به‌روز کنید (بیلد ۶۰۰+) |

## یادآوری مهم درباره `input`

ماژول هفت پارامتر `input` با پیشوند `GF_` معرفی می‌کند. وقتی داخل اکسپرت
شما `#include` شود، این‌ها در پنجره تنظیمات اکسپرت ظاهر می‌شوند — که مطلوب است.

اگر اکسپرت شما از قبل متغیری به نام `GF_SpreadMult` یا مشابه دارد، تداخل
می‌کند. در آن صورت پیشوند را در ماژول عوض کنید.

# راهنمای کامپایل — رفع خطای `event handling function not found`

## معنای خطا

```
event handling function not found    MF15.mq4    1    1
```

کامپایلر فایل `MF15.mq4` را خوانده و **هیچ تابع رویدادی** در آن پیدا نکرده است.
MQL4 برای یک اکسپرت، وجود **حداقل `OnTick()`** را الزامی می‌داند.

خطا در «خط ۱ ستون ۱» گزارش می‌شود چون کامپایلر پس از خواندن کل فایل
متوجه می‌شود تابع مورد نیاز را ندارد — نه اینکه خط ۱ مشکل داشته باشد.

## سه علت ممکن

### علت ۱ — محتوای ماژول داخل فایل `.mq4` گذاشته شده

`GF63_Fixes.mqh` یک فایل **include** است، نه اکسپرت. اگر محتوایش را کپی
کرده باشید داخل `MF15.mq4`، فایل توابع `GF_` را دارد ولی `OnTick` ندارد.

**راه‌حل:** فایل `MF15.mq4` موجود در همین پوشه را استفاده کنید — کاملاً
خودکفاست و ۲۶ تابع + هر ۴ تابع رویداد را دارد.

### علت ۲ — فایل فقط `#include` دارد

اگر `MF15.mq4` فقط این یک خط است:

```mql4
#include <GF63_Fixes.mqh>
```

کافی نیست. باید پوسته اکسپرت هم باشد:

```mql4
#property strict
#include <GF63_Fixes.mqh>

int OnInit()  { GF_SelfTest(); return(INIT_SUCCEEDED); }
void OnTick() { }
void OnDeinit(const int reason) { }
```

### علت ۳ — فایل خالی یا فقط کامنت است

فایل تازه‌ساخته و هنوز محتوایی ندارد.

## راه‌حل قطعی — سه گام

### گام ۱ — بررسی کنید `MF15.mq4` فایل خودتان نیست

> ⚠ **مهم:** اگر `MF15.mq4` اکسپرت خودتان است و کد واقعی داخلش دارید،
> **آن را جایگزین نکنید.** در آن صورت بگویید تا محتوایش را تحلیل کنم.
> راه‌حل زیر فقط برای فایلی است که برای تست ساخته‌اید.

### گام ۲ — محتوا را جایگزین کنید

```
۱. فایل  goldfusion-review/MF15.mq4  را باز کنید
۲. کل محتوایش را انتخاب و کپی کنید  (Ctrl+A , Ctrl+C)
۳. در MetaEditor فایل MF15.mq4 خودتان را باز کنید
۴. کل محتوایش را انتخاب و با این جایگزین کنید  (Ctrl+A , Ctrl+V)
۵. ذخیره کنید  (Ctrl+S)
```

این فایل **کاملاً خودکفا** است:
- ✅ هر چهار تابع رویداد: `OnInit` / `OnTick` / `OnTimer` / `OnDeinit`
- ✅ کد ماژول اصلاحی داخلش قرار گرفته — **هیچ فایل include لازم نیست**
- ✅ تنها include آن `<stdlib.mqh>` است که در هر نصب MQL4 موجود است
- ✅ ۲۶ تابع، بدون هیچ تعریف تکراری

### گام ۳ — کامپایل

```
۱. مطمئن شوید پنجره ویرایش MF15.mq4 فعال است (فوکوس روی آن باشد)
۲. F7 را بزنید
۳. باید پیام "0 errors, 0 warnings" ببینید
۴. اکسپرت را روی چارت XAUUSD M15 بیندازید
```

> **نکته:** در MetaEditor دکمه F7 **همیشه فایل فعال** را کامپایل می‌کند.
> اگر پنجره فایل دیگری جلو باشد، اشتباه کامپایل می‌شود. این یکی از رایج‌ترین
> اشتباهات است.

## اگر باز هم خطا گرفتید

متن **دقیق** خطا و **شماره خط** را بفرستید. تفاوت این خطاها مهم است:

| خطا | معنا |
|---|---|
| `event handling function not found` | فایل تابع `OnTick` ندارد → محتوای `MF15.mq4` را جایگزین کنید |
| `'GF_XXX' - function not defined` | تابع ماژول پیدا نشد → یعنی `#include` هست ولی فایل نیست |
| `'OnInit' - function already defined` | دو `OnInit` دارید → یکی را حذف کنید |
| `cannot open file` | مسیر `#include` غلط است |
